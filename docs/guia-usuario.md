# Guía de Usuario — Bot de WhatsApp GEMMATEX

Este documento explica cómo usar el bot de WhatsApp de GEMMATEX como cliente.

---

## ¿Qué puede hacer el bot?

- Mostrar el catálogo de productos con precios
- Dar información de soporte técnico
- Mostrar horarios de atención y datos de sucursales

---

## Cómo iniciar

Envía cualquier saludo al número de WhatsApp de GEMMATEX:

```
hola
buenas
buenos días
hi
```

El bot responderá con un mensaje de bienvenida y el menú principal.

---

## Menú principal

Verás 3 opciones:

| Botón | Qué hace |
|-------|----------|
| 🛍 Ver Productos | Navegar el catálogo por categoría |
| 🔧 Soporte Técnico | Ver datos de contacto y abrir tickets |
| 🕘 Horarios | Ver horarios y sucursales |

---

## Navegar productos

1. Presiona **Ver Productos**
2. Elige una **categoría** (ej. EPSON, MAQUINAS GX, PAPELES...)
3. Elige una **subcategoría**
4. Verás una lista de productos — elige uno para ver detalles
5. El bot enviará la **imagen**, **nombre**, **precio** y **stock**
6. Luego podrás:
   - **Consultar** → recibir datos de contacto para hacer una compra
   - **Más productos** → volver a la lista
   - **Menú principal** → volver al inicio

## Preguntas frecuentes

**¿El bot guarda mis datos?**
Solo recuerda tu estado de conversación por 30 minutos de inactividad. No almacena datos personales.

**¿Puedo escribir texto libre?**
El bot funciona con los botones del menú. Si escribes texto fuera de un saludo, te redirigirá al menú principal.

**¿Los precios son definitivos?**
Los precios mostrados son de referencia. Para precios actualizados o descuentos especiales, usa la opción **Consultar**.

**¿Cómo reinicio la conversación?**
Escribe "hola" en cualquier momento para volver al menú principal.
